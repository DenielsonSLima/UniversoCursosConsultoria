# Checklist Android

- [ ] Android Studio instalado e atualizado.
- [ ] SDK/JDK reconhecidos pelo Android Studio.
- [ ] Emulador criado com Google APIs.
- [ ] Projeto usa `br.com.universocc.aluno`.
- [ ] App abre no login do aluno.
- [ ] Turnstile funciona no WebView Android.
- [ ] Login por senha concluído.
- [ ] Botão voltar não fecha o app indevidamente.
- [ ] Links, PDF, downloads e checkout testados.
- [ ] Upload, câmera, microfone e anexos testados quando aplicável.
- [ ] APK debug instalado em aparelho físico.
- [ ] Layout validado em tela pequena, grande e com teclado aberto.
- [ ] Teste em Android 7/API 24 e versão Android atual.
