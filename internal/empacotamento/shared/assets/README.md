# Fontes visuais nativas

Não copie automaticamente os ícones PWA para as lojas. Antes de gerar os assets nativos, preparar:

- `icon-source.png`: 1024 × 1024, fundo branco, sem transparência e símbolo visualmente centralizado;
- `splash-source.png`: 2732 × 2732, fundo institucional e logo dentro da área segura central;
- `push-icon-source.png`: Android monocromático, branco e transparente fora do desenho;
- versão foreground/background para o adaptive icon Android.

Fontes atuais que podem orientar o trabalho:

- `public/aluno/icons/app-icon-v3-512.png`;
- `public/aluno/icons/apple-touch-icon-v3.png`;
- `public/LogoUniverso.png`.

Não versionar certificados, keystores, arquivos `.p8`, senhas ou credenciais de loja nesta pasta.
