# Checklist iOS

- [ ] Xcode atualizado e licença aceita.
- [ ] Command Line Tools selecionadas.
- [ ] Projeto usa `br.com.universocc.aluno`.
- [ ] App abre no login do aluno.
- [ ] Turnstile funciona em `capacitor://localhost`/WKWebView.
- [ ] Login por senha concluído.
- [ ] Cadastro, recuperação e logout testados.
- [ ] Links, PDF, downloads, vídeos e checkout testados.
- [ ] Safe areas e teclado validados no simulador e no iPhone.
- [ ] Personal Team instala o app no aparelho próprio.
- [ ] Reabertura mantém sessão corretamente.
- [ ] Fluxo de exclusão de conta planejado antes da submissão.
- [ ] Compras digitais revisadas antes da submissão.
