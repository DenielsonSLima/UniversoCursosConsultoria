# Asaas outros-creditos

Detached payment link rules for Financeiro > Outros Creditos belong here.

This module is intentionally separated from course checkout modules:

- No EAD-specific fee/installment rule belongs here.
- No tecnico enrollment/cycle rule belongs here.
- Receivables without `matricula_id` and with categoria `OUTROS_CREDITOS`
  are handled here.
